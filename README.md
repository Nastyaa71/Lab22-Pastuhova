Группа: ИСП-252

1. в Dictionary уникальны ключи (значения могут повторяться). В HashSet уникален каждый элемент.

2. HashSet.Add() при повторе возвращает false и просто не добавляет элемент (исключения нет). Dictionary.Add() при существующем ключе вызывает исключение. Для изменения значения в словаре используют dictionary[key] = value.

3. TryGetValue() не выбрасывает исключение при отсутствии ключа, а возвращает false. Прямое чтение dictionary[key] при отсутствующем ключе приводит к исключению.
